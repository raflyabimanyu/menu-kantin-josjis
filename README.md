Cara menjalankan:
1. Masukan folder kedalam file xampp/htdocs(jika menggunakan XAMPP).
2. Buka aplikasi XAMPP
3. Aktifkan module Apache dan MySQL
4. Buka browser dan ketik http://localhost/phpmyadmin/
5. Buat database menu_kantin
6. Import file app.sql
7. ketik http://localhost/menu_kantin_josjis/login.php di browser
8. Input nama Username dan Password
    ~Jika ingin login sebagai admin; 
     Username:  admin 
     Password:  admin123
    ~Jika ingin login sebagai user;
     Username:  rina
     Password:  rina123
